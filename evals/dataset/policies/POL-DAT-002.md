# Data export and portability

**DAT-002.1** Every tier can export workspace data from Settings → Export, in
JSON and CSV formats.

**DAT-002.2** An export is prepared within 24 hours and the download link
remains valid for 7 days.

**DAT-002.3** Suspended accounts retain export access, since suspension is
read-only rather than a lockout.

**DAT-002.4** In a Team workspace, only an owner or admin may export the full
workspace. Members can export only content they authored.

**DAT-002.5** Support can regenerate an expired export link on request from
the account owner.
